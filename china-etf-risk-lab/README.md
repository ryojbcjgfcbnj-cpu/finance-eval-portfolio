# China ETF Research Agent Lab

**中国 ETF 波动率预测与组合风险控制。** 使用六只人民币 ETF 的真实行情，比较五种波动率预测方法，以时间前推评估、移动区块置信区间和扣费组合实验检验预测模型的应用价值。实现了带正则化的 QLIKE 求解器。

- [研究方法、数学推导与结果解读](RISK_METHODS.md)
- [实验报告](examples/RISK_REPORT.md) · [机器可读结果与数据来源](examples/risk_report.json)

```powershell
python -m pip install -r requirements.txt
python risk_study.py
python -m unittest -v
```

风险实验输出到 `outputs/risk_study`，包括汇总报告、逐日预测损失、组合净值和每次拟合的标签时点审计。数据下载和缓存沿用下文的研究环境。

## 交互应用

[组合风险工作台](risk-workbench/README.md) 支持权重与限额检查、风险归因、压力情景、简报导出及模型比较。

[A 股行情与风险扫描](MARKET_SCALE.md) 提供交易日对齐、增量导入、历史波动排名和单机计算压测。

## 动量研究环境

研究量化 Agent 的实验设计、工具使用、错误诊断与后训练。当前版本提供真实历史行情上的可复现研究环境，面向中国场内 ETF，覆盖多资产策略、交易成本、滚动选择、样本外评估和工具调用轨迹。

## 快速运行

Python 3.10+，在项目目录执行。

```powershell
python -m pip install -r requirements.txt
python research_lab.py
python -m unittest -v test_research.py
```

首次运行从 Yahoo Finance chart 接口下载数据，之后使用本地缓存。下载失败时程序明确报错。使用 `--refresh` 主动更新快照，更新后的历史价格可能因数据提供方修订而变化。

```powershell
python research_lab.py --cost-bps 10 --output outputs/cost10
```

每次运行将覆盖指定输出目录。网络下载使用 Python 标准库，无需 API Key。接口可用性取决于数据提供方。

## 策略与选择协议

候选集合在运行前固定，共九种配置。

- 时间序列趋势，根据 21、63、126 日收益的正负选择资产。
- 相对动量，选择过去 21、63、126 日收益最高的两只资产。
- 短期反转，选择过去 21、63、126 日收益最低的两只资产。

持仓按过去 63 日的逆波动率分配，使用资产加权波动率之和作为组合波动率上界，将目标控制在年化 10%，总仓位最多为 100%。相对动量与反转使用相同窗口集合，便于控制变量比较；126 日反转属于对照假设。

2018—2022 年逐年滚动，每次在此前三年内比较九个候选，依据 `Sharpe(rf=0) - 2 * 最大回撤` 选一个配置，再在下一年评估。各年组合独立建仓、退出，边界成本均计入。最终配置仅依据 2020—2022 年选择，2023—2024 年作为本轮最终测试。

最终测试另外比较每 21 日再平衡的等权组合、沪深300ETF买入持有和现金。分别报告收益、年化收益、波动率、Sharpe、最大回撤、换手和成本。同一最终策略还在单边 0、5、20 bps 下进行成本敏感性分析，敏感性分析中配置固定。

## 成交与资金记账

收盘 s 日的信号在 s+1 日收盘执行，从 s+1 到 s+2 开始赚取收益。每 21 个交易日再平衡。每个评估区间的初始持仓在首个收益日之前的收盘建立，信号再滞后一天。

资产持仓逐日按价格变化漂移。再平衡求解扣除交易成本后的净值，使目标持仓、现金和费用满足自融资约束。成本按成交名义金额双向计提，包含首次建仓、再平衡和最后退出。换手为成交名义金额除以交易前净值。

允许碎股，多头和现金，现金利率及 Sharpe 无风险利率均取零。调整价格用于模拟含分配调整的收益变化。股票ETF遵循隔日卖出，本日频框架的持仓至少隔一交易日；债券和黄金ETF同样使用该低频调仓约定。100份交易单位、最低佣金、涨跌停、停牌与成交量约束尚未建模。分红到账和现金流仍采用调整价格近似。

固定六只存续 ETF 存在资产选择偏差。数据为当前快照，未经 point-in-time 历史版本验证。策略与基准的风险水平不同，应同时比较暴露和波动率。测试结果用于进一步修改策略之后，该区间应归入开发数据，并重新设置独立测试。

## 学习顺序

1. 阅读 `market_data.py`，理解调整价格、交易日对齐、缓存和数据版本。
2. 阅读 `targets`，解释因子窗口、排名、逆波动率和仓位约束。
3. 手算 `rebalance` 的资金守恒，检查 `simulate` 的信号、成交和收益日。
4. 比较逐年结果，分析策略失效与参数选择不稳定的原因。
5. 阅读轨迹，定义 Agent 能调用的研究工具和预算。

## 后续研究

当前实验决策使用固定候选搜索。下一阶段将接入单个 LLM 研究者，限制可见数据范围、工具参数和调用预算，记录假设、工具执行、失败修复与总结。

随后复核轨迹并构造 SFT 数据，用小模型 LoRA 训练，对照同模型、同工具与同预算下训练前后的表现。任务完成率、泄漏与违规行为、结果复现、研究质量、金融表现和工具成本分别评估。奖励建模从可验证任务开始，例如修复前视偏差、实现符合接口的因子和诊断成本失效。

当前尚未训练 LLM 权重，工具日志与训练用对话数据需要进一步转换和复核。模型自主执行代码时，训练与开发数据在独立受限环境中提供，最终测试由独立评估入口运行。
