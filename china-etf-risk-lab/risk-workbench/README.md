# 中国 ETF 组合风险工作台

打开 `dist/index.html` 即可演示。页面使用随项目生成的衍生风险快照，直接在浏览器内计算，无需 API Key。若要重新生成快照，安装父目录的 `requirements.txt` 后运行 `python build_snapshot.py`。数据缓存和研究汇总须来自同一份历史行情。

## 调仓前审查

1. 选择历史日期和预测模型，输入组合净值、限额和六只资产的权重。
2. 检查预测年化波动率、方差贡献和情景损益，调整价格冲击以复核集中风险。
3. 对超限组合应用比例缩放，查看剩余现金并导出风险简报。
4. 在模型验证页切换自助抽样区块长度与交易成本，比较样本外预测结果和组合表现。

每个快照保存各资产由历史预测得出的方差，以及 63 日收缩相关矩阵。组合方差采用 `wᵀΣw`，方差贡献采用 `wᵢ(Σw)ᵢ / (wᵀΣw)`，可为负值。压力损益采用净值乘以各资产权重和冲击的内积。比例缩放假定剩余部分为零风险现金。缩放只改变页面上的模拟权重。

评估日为历史快照，样本外模型结果沿用父项目的时间隔离和成本模型。压力冲击是可修改的示例参数。行情快照由下载时的调整收盘价生成，覆盖 2014—2024 年的中国 ETF 数据。
